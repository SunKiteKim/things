# 금액 계산 정책

1. 상품에 저장된 기본 판매가에 가장 유리한 유효 기획전 할인을 적용합니다.
2. 타임세일에 전시된 상품은 행사 종료 시각까지 타임세일 할인을 추가 적용합니다. 단가는 원 단위 반올림하며, 기획전·타임세일 적용 후 판매 단가는 최소 1원입니다.
3. 행사 적용 단가에 수량을 곱한 상품금액을 기준으로 각 쿠폰의 조건과 할인액을 계산합니다.
4. 중복 가능 쿠폰끼리는 같은 상품금액을 기준으로 산출한 할인액을 합산합니다. 중복 불가 쿠폰은 단독 사용하며, 총 쿠폰 할인은 상품금액에서 1원을 뺀 금액까지만 적용합니다. 상품이 있는 주문은 할인 후에도 상품금액이 최소 1원 남습니다.
5. 쿠폰 할인 후 상품금액이 30,000원 이상이면 배송비는 0원, 미만이면 3,000원입니다. 기준 금액에 배송비는 포함하지 않습니다. 빈 장바구니는 배송비가 0원입니다. 할인 후 상품금액이 1원이면 최종 결제금액은 배송비 포함 3,001원입니다.
6. 최종 결제금액은 상품금액 - 쿠폰 할인 + 배송비입니다. 화면과 주문 생성에서 같은 정책을 사용합니다.

쿠폰을 선택하지 않은 첫 진입에서는 최대 할인 조합을 제안합니다. 사용자가 쿠폰을 모두 해제하면 미적용 선택을 유지합니다. 장바구니 변경으로 선택한 쿠폰이 모두 무효가 되면 다시 최대 할인 조합을 제안합니다.

검증 예: 무료배송 기준의 직전/동일/직후 금액, 쿠폰으로 무료배송 기준 미달, 중복 불가 쿠폰 조합, 총 할인 상한, 타임세일 종료, 수량 증가와 단가 반올림.

## 표시와 검증

- 메인·상세·장바구니의 대표 단가는 행사 적용 후, 쿠폰 적용 전 가격입니다. 개인 쿠폰 예상가는 별도로 표시합니다.
- 주문서의 쿠폰 코드와 대상 상품은 표시된 할인과 함께 전달합니다. 주문 생성 시 서버가 재계산한 금액이 화면과 달라지면 결제를 진행하지 않고 갱신된 금액 확인을 요청합니다.
- 할인 내역은 전체 할인 상한을 적용한 실제 할인액을 표시합니다. 코드 순서로 할인액을 배정하고, 상품별 원 단위 배분은 최대 잔여 방식으로 합계를 보존합니다.
- 상품쿠폰 1장 최적 적용은 현재 선택한 장바구니 쿠폰과 중복 가능 여부, 실제 할인액, 배송비를 비교합니다. 상품쿠폰 미적용이 더 저렴한 경우도 포함하며, 여러 상품쿠폰의 전체 조합 최적화를 의미하지 않습니다.
- Today’s Pick은 재고가 있는 상품을 날짜 기준으로 선정합니다. 상품 목록·재고·가격 변경 시 같은 날에도 선정 결과가 달라질 수 있습니다. ‘현재 상품·가격 기록 저장’으로 화면의 선정 날짜·상품 ID·가격·재고를 보관할 수 있습니다. 이후 같은 데이터를 복원하는 기능은 아닙니다.
